# MarkCard Studio 字号评估

> 状态：评估 + 首轮微调（2026-10-21）
> 范围：应用界面（标题栏、工具栏、Inspector、素材/贴纸/发布/运营、状态栏）与卡片排版。
> 结论：**整体偏小**。9–10px 的中文界面文字偏多，11px 是桌面端可读下限；建议把正文/说明提升到 12–13px，meta 11px，micro 10px，并停止使用 9px 作为正文。

---

## 1. 现状量化

对 `src` 内的字号 token 做了一次统计：

| 字号 | 次数 | 主要用途 | 评价 |
| --- | --- | --- | --- |
| 9px | 7 | 徽标、计数、Picker 辅助 | 过小，中文不宜作为正文 |
| 10px | 32 | 说明、标签、徽标、下拉 | 偏小，仅适合徽标/计数 |
| 11px | 48 | 说明、设置项、Picker 名称、按钮 | 接近下限，长文偏吃力 |
| 12px（text-xs） | 109 | 主要 UI 文本、按钮、设置正文 | 桌面端可用，但偏密 |
| 14px（text-sm） | 24 | 标题/强调/部分正文 | 合适 |
| 15–16px | 少量 | Inspector/品牌/标题 | 合适 |

结论：**12px 是当前事实上的正文基准，但大量辅助文字落在 9–11px**；在 1280/1024 宽度下密度更高，阅读压力明显。

| 区域 | 当前字号 | 评价 | 建议 |
| --- | --- | --- | --- |
| 标题栏品牌 | 16px；版本 10px | 品牌合适，版本偏小 | 版本 → 11px |

| 工具栏按钮 | 12px | 合适 | 保持 |
| 创作子模式 | 11px | 偏小 | 12px |
| 主题下拉说明 | 10px | 过小 | 11px |
| Inspector 标题 | 15px | 合适 | 保持 |
| Inspector 段位 | 10px | 偏小 | 11px |
| Inspector 设置正文 | 10–12px 混用 | 不统一，部分过小 | 正文 12px，说明 11px，徽标 10px |
| 设置面板说明 | 10–11px | 偏小、密度高 | 说明 → 11–12px |
| 预览头 | 12–16px | 基本合适 | 保持 |
| 预览缩略图 | 10–11px | 偏小 | 11px |
| 状态栏 | 11–14px | 中间信息偏小 | 12px |
| 贴纸选择器 | 9–11px | 明显偏小 | 名称/位置/提示 → 11px，按钮 12px |
| 发布/运营占位 | 11px | 偏小 | 12px |
| 素材库占位 | 12px | 合适 | 保持 |
| 卡片页眉/页脚 | 11px（设计视口） | 导出后约 26px，实际可读 | 不改，避免影响导出 |
| 卡片正文/标题 | 0.75–1.15rem + clamp | 导出分辨率下正常 | 不改，按画布比例调整 |

> 关键区分：**卡片内部字号是“设计视口字号”，会被导出放大**；界面字号是屏幕实际字号。不要为了预览里看着大而改卡片 CSS，否则会改变导出成品。

## 3. 建议的字号阶梯

```text
Display     20–24px / 1.2   页面级大标题（运营概览等）
Page title  16–18px / 1.3   面板/页面标题
Section     14px    / 1.4   分区标题
Body        13px    / 1.5   主要正文
Compact     12px    / 1.5   密集界面正文（当前基准）
Meta        11px    / 1.4   说明、时间、路径、辅助信息
Micro       10px    / 1.3   徽标、计数、仅短词
```

规则：

1. **正文不用 9px**；10px 只用于徽标/计数/极短标签。
2. 中文正文最低 11px，推荐 12–13px。
3. 同一角色只用一档：说明统一 11px 或 12px，不要 10/11/12 混用。
4. 徽标可以 10px，但必须配足够对比度和字重。
5. 行高：正文 1.5–1.6，说明 1.4，标题 1.2–1.3。

## 6. 风险

- **放大字号会导致密集面板溢出**：Inspector 只有 300–360px，设置项多；建议先改说明/正文，不动控件高度，逐项验收。
- **中英文长度差异**：英文更长，按钮/标签需要 `whitespace-nowrap` 或可换行；不要用固定宽度。
- **窄屏**：1280/1024 下应优先隐藏次要文字，而不是继续缩小字号。
- **卡片与界面混淆**：卡片字体由主题/CSS 控制，不能按屏幕预览效果直接放大。

---

## 7. 验收

- [ ] 1600 / 1280 / 1024 宽度下，正文 ≥ 12px、说明 ≥ 11px、无 9px 正文；
- [ ] Inspector/设置面板不出现文字截断或控件溢出；
- [ ] OpenMoji 选择器名称/位置/提示可读，网格不因字号增大而破版；
- [ ] 中英文切换不溢出；
- [ ] 暗色模式对比度足够；
- [ ] 卡片预览与导出尺寸不受 UI 字号调整影响。

---

## 8. 结论

**当前整体字号偏小，尤其是 9–10px 的中文辅助文字。** 12px 可以作为密集界面的正文基准，但建议把说明提升到 11–12px、正文 12–13px，并把 9px 限制在极少数徽标/计数场景。本轮已先修 OpenMoji/Inspector/新工作区，现有设置面板建议做一轮单独的 typography pass。
