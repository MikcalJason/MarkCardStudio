# OpenMoji assets

These 48 SVG stickers are from [OpenMoji](https://openmoji.org/) and are
licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).

They are bundled locally so previews and exports work offline. The curated
selection covers ideas, work, creative, nature, and everyday-life categories.
Source: [hfg-gmuend/openmoji](https://github.com/hfg-gmuend/openmoji), color SVG
set, retrieved 2026-10-21.

Copyright and license information is retained here for attribution. If you add
or replace an OpenMoji asset, update the catalog in
`src/config/openmoji.js` and keep this attribution intact.
